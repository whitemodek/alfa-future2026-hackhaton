# AutoML — Альфа Хакатон

Бэкенд агента: читает задачу, вызывает LLM, запускает Python-код и сохраняет
лучший результат в `submission.csv`. ML-модуль подключается отдельно.

## Запуск

Нужен Python 3.12. Зависимости платформы лежат в `requirements.txt`.
Для работы только с бэкендом достаточно:

```sh
pip install openai==1.68.2 httpx==0.28.1 pydantic==2.10.6 psutil==6.1.1
```

Задайте переменные окружения:

```sh
export OPENAI_API_KEY='ключ'
export OPENAI_BASE_URL='адрес прокси организаторов'
export OPENAI_MODEL='qwen/qwen3.8-27b'

python3 solution.py /path/to/task.md
```

В PowerShell вместо `export NAME='...'` используется `$env:NAME='...'`.
Файл `.env` автоматически не загружается и в Git не попадает.

Результат появится рядом с `task.md`. Логи и код экспериментов — в папке
`.agent-*` там же. Если очередной эксперимент упадёт, агент сохранит предыдущий
проверенный результат. Если результата нет, завершится с ненулевым кодом.

## ML-модуль

Положить `ml_backend.py` в корень проекта. Он получает пути к JSON-запросу и
JSON-ответу через аргументы командной строки, выполняет эксперимент и сохраняет
предсказания. Дополнительные модули нужно называть `ml_*.py`, чтобы они попали в ZIP.

Формат запроса и ответа описан в [docs/ML_CONTRACT.md](docs/ML_CONTRACT.md).
В `examples/mock_ml_backend.py` есть заглушка для проверки подключения.

## Тесты и сборка

```sh
python -m unittest discover -s tests -v
python pack_solution.py dist/solution.zip
```

Тесты проверяют бэкенд без обучения моделей и запросов к платному API.
В архив попадут файлы решения, корневые `ml_*.py` и `requirements.txt`.

Лимиты заданы в `agent_config.py`, менять их можно через переменные `AGENT_*`.
По умолчанию: 175 минут на задачу, из них 15 на финализацию, до 8 потоков
и порог памяти 28 000 МиБ. Лимит токенов действует на один запуск; общий
денежный бюджет команды нужно отслеживать отдельно.

Сгенерированный код запускается в отдельном процессе, но это не песочница.
Для реальных задач нужна изолированная среда. Подробнее — в
[docs/SECURITY.md](docs/SECURITY.md).
