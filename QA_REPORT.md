неизменённый `requirements.txt`. Нет ключей, данных, моделей, тестов или журналов.

## Финальный архив на данных организаторов

Проверка запускает собранный ZIP в отдельном каталоге. CatBoost обучается реально;
внешняя LLM заменена локальным HTTP-сервером с командой finish. Проверены код
завершения 0, success=true, формат, число строк и порядок ID относительно шаблона.

| Задача | Строк CSV | Holdout | Время |
|---|---:|---:|---:|
| Регрессия | 22 449 | RMSE 45,6871 | 37,08 с |
| Многоклассовая | 41 166 | Macro F1 0,59541 | 101,52 с |

Обе выбранные модели обучены на полном train. В регрессии search выбрал
глубину 8 вместо 6: RMSE 47,5278 → 45,6871 на одном разбиении. В классификации
первое обучение было дорогим, поэтому дополнительные конфигурации пропущены.
Значение final=false у кандидата полного train означает обычный эксперимент;
признак fit_scope=full_train подтверждает объём обучения.

Регрессия проверяется на полном периоде 5, обучается на периодах 1–4;
test относится к периоду 6. В классификации точные дубликаты признаков остаются
в одной группе. Между частями валидации таких пересечений нет. Предыдущие оценки
случайного holdout нельзя напрямую сравнивать с новыми. Это не метрики скрытого test.

Локальный отчёт: `.test-temp/offline-e2e5-report.json`.

## Настоящий API и бюджет

Пользователь разрешил передачу задач и вывода инструментов через
`changellenge.up.railway.app`: до 80 000 токенов на задачу, 160 000 суммарно.
Интеграция с этим прокси проверена на обеих задачах на промежуточных сборках.
Последние изменения поиска проверены в финальном ZIP локально, без новых платных вызовов.

Суммарный расход всех реальных проверок:

| Задача | Токены |
|---|---:|
| Регрессия | 61 886 |
| Многоклассовая | 67 235 |
| Всего | **129 121** |

Лимиты соблюдены. Один запуск регрессии остановился до первого запроса из-за
слишком большого резерва контекста и потратил ноль токенов; дублирование стартовых
результатов после этого убрано и реальный API-вызов повторён успешно.
Остановка BudgetExceeded сохраняет корректный CSV; код завершения остаётся 0,
если проверенный результат уже есть.

Входные файлы последних реальных проверок совпали с оригиналами по SHA-256,
ключ в журналах не найден. Отчёты `final-e2e-report.json`, `final-e2e2-report.json`,
`final-e2e3-report.json`, `final-e2e4-report.json` находятся в `.test-temp` и
не входят в Git или ZIP. `qa/check_tokens.py` суммирует повторные запуски и
консервативные начисления после неопределённых API-ошибок.

## Сохранение результатов и ограничения

Дообучение использует выбранное число деревьев без повторного поиска. Перед ним
сверяются данные, модель, параметры, разбиение и воспроизводимость оценки.
При нехватке времени или ошибке остаётся проверенная модель. Оркестратор делает
одну попытку полного дообучения перед завершением, включая остановку API-цикла;
отмена пользователем не запускает новую работу.

Поддерживается один табличный таргет. Автоматический выбор валидации — эвристика;
для известных групп или времени нужно явно задавать group_columns/time_column.
Полного группового CV и возобновления сессии после жёсткого завершения нет.
Подпроцесс не является песочницей; границу безопасности предоставляет платформа.
Формальная проверка метрик не подтверждает место на закрытом лидерборде.
