## Блокер до первого сабмита

**B0. Интерфейс не сверен с baseline.py.** Агент запускается как `python3 solution.py task.md`, берёт
`OPENAI_API_KEY` / `OPENAI_BASE_URL` / `OPENAI_MODEL` и пишет `submission.csv` рядом с `task.md`.
По условию переменные, запуск и формат вывода зафиксированы в baseline.py. Если там другое, будет 0 баллов на всех задачах.
Нужно проверить: аргументы запуска, имена env-переменных (ключ, URL, модель, путь к данным, путь к ответу),
имя и место выходного файла, доступен ли каталог с данными на запись (см. BUG-9).

## Риски, которые стоит проверить

- **Qwen через прокси организаторов.** Принимает ли он `parallel_tool_calls=False` и `tools`? Если вернётся 400,
  агент сразу завершится без сабмита. Проверьте одним реальным запросом.
- **Таймаут API 90 с.** Qwen3 с режимом размышлений на 4096 токенов ответа может не уложиться — тогда будут ретраи и
  расход бюджета. Посмотрите время ответа в `events.jsonl`.
- **Обрезка контекста** удаляет старые шаги целиком, вместе с результатами разведки данных: агент «забывает» структуру
  датасета. Стоит держать короткую сводку (тип задачи, таргет, метрика, лучший скор) в закреплённом сообщении.
- **8 потоков на 2 CPU** в моём контейнере дали 3 минуты на крошечные данные. На платформе 8 CPU — ок, но
  при параллельных моделях (n_jobs × OMP) будет переподписка.
- **Выбросы и RMSE.** В синтетической регрессии бустинг на CV проиграл константе (74 против 69 RMSE). Бэкенд верно оставил
  лучшую, но ML-часть должна уметь это заметить (лог-таргет, обрезка, Huber).
- **Бинарная задача с AUC** (возможна на private): нужны вероятности, а не метки 0/1. Промпт об этом не говорит.
- В промпте нет списка доступных библиотек из requirements.txt и лимитов CPU/RAM. LLM может тратить шаги на импорт
  того, чего нет.

## Как пользоваться QA-файлами

```sh
python -m unittest discover -s tests -v              # все тесты, включая QA
python qa/gen_tasks.py qa_tasks --small              # 3 синтетические задачи (регрессия/мультикласс/бинарная)
python pack_solution.py dist/solution.zip
python qa/run_local.py dist/solution.zip qa_tasks --limit-min 20   # прогон «как платформа» с реальным LLM
python qa/check_submission.py qa_tasks/reg_outliers  # формат + метрика по скрытым ответам
```

`run_local.py` распаковывает ZIP в чистую папку, запускает каждую задачу отдельно, убивает процесс по лимиту и
проверяет сабмит. Команду запуска в `COMMAND` нужно привести к baseline.py.
