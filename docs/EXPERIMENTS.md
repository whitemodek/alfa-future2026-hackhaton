# Проверка качества моделей

25 октября 2026. Использованы только train, признаки test и условия организаторов.
Ответы скрытого теста недоступны. Все значения ниже относятся к holdout.

## Разбиение

В регрессии train содержит периоды 1–5, а test — только период 6.
Проверка теперь использует целиком период 5: 35 000 строк обучения и
18 308 строк валидации. Порядок строк исходного CSV не влияет на выбор.

В классификации 43,94% строк прежней случайной валидации имели точный
дубликат признаков в обучающей части. В настоящем test таких строк только
8,64% относительно полного train. Теперь одинаковые наборы признаков остаются
в одной группе: 70 136 строк обучения и 17 534 строки валидации, без пересечений.
Все десять классов присутствуют в обеих частях. ID исключён из признаков.

Новые оценки нельзя напрямую сравнивать с прежним случайным holdout.
Группировка устраняет точные дубликаты, но не доказывает отсутствие всех
скрытых связей между наблюдениями или совпадение распределений train/test.

## Сравнение настроек

Регрессия: одинаковый holdout периода 5, seed 42, learning_rate 0,06,
до 800 деревьев, early stopping 60, четыре потока.

| Глубина | Выбранных деревьев | RMSE |
|---|---:|---:|
| 4 | 129 | 46,8863 |
| 6 | 70 | 47,5278 |
| 8 | 69 | 45,6871 |

Глубина 8 перспективна для этой задачи. Общая настройка для всех задач
не менялась по результату одного набора данных; агент может сравнивать глубины.
Финальный встроенный `search` сам повторил эти сравнения за 18,39 секунды,
выбрал глубину 8 и дообучил 69 деревьев на всех 53 308 строках. Поиск запускает
соседние конфигурации только при быстром первом обучении, максимум три попытки.
Отчёт: `.test-temp/search-regression-proof.json`.

В классификации прямая ранняя остановка по Macro F1 оказалась хуже:
0,59541 против 0,61539 у контрольного запуска по loss на том же разбиении.
Этот вариант отклонён: F1 может долго стоять на плато до улучшения редких классов.

Принятый вариант использует loss для остановки и выбирает число деревьев по
целевой метрике среди уже обученных. На одной общей траектории из 217 деревьев:

| Выбор контрольной точки | Деревьев | Macro F1 |
|---|---:|---:|
| По loss | 217 | 0,602170 |
| По Macro F1 | 212 | 0,603125 |

Прирост небольшой: 0,000956. Это сравнение одной траектории, не разных
запусков с разным временем обучения. Проверенная метрика записывается до refit;
полная модель не получает новую оценку на уже использованных для обучения строках.

Локальные исходные отчёты: `.test-temp/ml-robust-experiments.json` и
`.test-temp/primary-selection-verification.json`. Они и данные не входят в ZIP.
