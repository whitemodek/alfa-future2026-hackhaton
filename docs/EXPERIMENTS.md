# Проверка качества моделей

25 октября 2026. Использованы только train, признаки test и условия организаторов.
Ответы скрытого теста недоступны. Все значения ниже относятся к holdout.

## Разбиение

В регрессии train содержит периоды 1–5, а test — только период 6.
Проверка теперь использует целиком период 5: 35 000 строк обучения и
18 308 строк валидации. Порядок строк исходного CSV не влияет на выбор.

В классификации 43,94% строк прежней случайной валидации имели точный
дубликат признаков в обучающей части. В настоящем test таких строк только
8,64% относительно полного train. Теперь одинаковые наборы признаков остаются
в одной группе: 70 136 строк обучения и 17 534 строки валидации, без пересечений.
Все десять классов присутствуют в обеих частях. ID исключён из признаков.

Новые оценки нельзя напрямую сравнивать с прежним случайным holdout.
Группировка устраняет точные дубликаты, но не доказывает отсутствие всех
скрытых связей между наблюдениями или совпадение распределений train/test.

## Сравнение настроек

Регрессия: одинаковый holdout периода 5, seed 42, learning_rate 0,06,
до 800 деревьев, early stopping 60, четыре потока.

| Глубина | Выбранных деревьев | RMSE |
|---|---:|---:|
| 4 | 129 | 46,8863 |
| 6 | 70 | 47,5278 |
| 8 | 69 | 45,6871 |

Глубина 8 перспективна для этой задачи. Общая настройка для всех задач
не менялась по результату одного набора данных; агент может сравнивать глубины.
Финальный встроенный `search` сам повторил эти сравнения за 18,39 секунды,
выбрал глубину 8 и дообучил 69 деревьев на всех 53 308 строках. Поиск запускает
соседние конфигурации только при быстром первом обучении, максимум три попытки.
Отчёт: `.test-temp/search-regression-proof.json`.

В классификации прямая ранняя остановка по Macro F1 оказалась хуже:
0,59541 против 0,61539 у контрольного запуска по loss на том же разбиении.
Этот вариант отклонён: F1 может долго стоять на плато до улучшения редких классов.

Принятый вариант использует loss для остановки и выбирает число деревьев по
целевой метрике среди уже обученных. На одной общей траектории из 217 деревьев:

| Выбор контрольной точки | Деревьев | Macro F1 |
|---|---:|---:|
| По loss | 217 | 0,602170 |
| По Macro F1 | 212 | 0,603125 |

Прирост небольшой: 0,000956. Это сравнение одной траектории, не разных
запусков с разным временем обучения. Проверенная метрика записывается до refit;
полная модель не получает новую оценку на уже использованных для обучения строках.

Локальные исходные отчёты: `.test-temp/ml-robust-experiments.json` и
`.test-temp/primary-selection-verification.json`. Они и данные не входят в ZIP.

## Дополнительный этап: три семейства и повторная проверка

### Регрессия

Настройки проверены на периоде 5 (обучение 1–4) и независимо на периоде 4
(обучение 1–3). Число деревьев для каждого временного holdout выбиралось на нём;
это два временных backtest, не скрытый тест. Наборы весов смеси фиксированы.

| Модель | RMSE периода 5 | RMSE периода 4 |
|---|---:|---:|
| CatBoost depth8, patience60 | 45,6871 | 43,8835 |
| CatBoost depth8, patience100 | 45,3563 | 43,5792 |
| XGBoost One-Hot depth4, seed42 | 44,6235 | 45,2457 |
| XGBoost One-Hot depth6, seed42 | 43,8745 | 47,7981 |
| 50% CatBoost + 50% XGBoost depth4 | 44,2098 | 43,4851 |
| 50% CatBoost + 25% XGBoost42 + 25% XGBoost17 | 43,2724 | 43,4944 |

Глубина 6 XGBoost отклонена как общий дефолт: улучшение первого периода не
подтвердилось на втором. Дополнительный seed используется только в фиксированной
смеси с CatBoost, если обучение дешёвое. Одиночный удачный seed не продвигается.
Вторичный выигрыш ансамбля небольшой; его доверительный интервал пересекает ноль.

XGBoost с native-категориями дал около RMSE 55 на периоде 5. На нём 17,43%
строк содержат неизвестный предыдущим периодам State_Factor. Плотный One-Hot
исправил этот случай и воспроизвёл результат 44,6235 в настоящем runtime-адаптере.
Словари категорий обучаются на train-fold; числовые нули остаются нулями.
Поиск ограничивает расширение плотной матрицы до 50 млн ячеек.

Исходные отчёты: `.test-temp/night-regression-summary.json`,
`.test-temp/night-regression/adapter-report.json`, `fixed-seed-bags.json`.

### Классификация

Для этого сравнения число деревьев выбиралось на внутреннем групповом holdout,
затем модель обучалась на внешнем train и проверялась на нетронутом внешнем
holdout. Проверены исходное групповое разбиение и отдельное с seed17.
Поэтому эти оценки не тождественны оценкам обычного runtime с early stopping
на его основной валидации. Все значения — Macro F1 по сырым вероятностям.

| Модель | Основной holdout | Подтверждающий seed17 |
|---|---:|---:|
| CatBoost depth6, ограниченный бюджет | 0,59939 | 0,61185 |
| LightGBM31, без весов | 0,62220 | 0,64263 |
| LightGBM31, sqrt-веса | 0,64086 | 0,66113 |
| LightGBM63, sqrt-веса | 0,64148 | 0,66294 |
| LightGBM127, sqrt-веса | 0,64843 | 0,65874 |
| XGBoost6, без весов | 0,60640 | 0,62861 |
| XGBoost6, sqrt-веса | 0,65191 | 0,64997 |
| XGBoost8, sqrt-веса | 0,64228 | 0,64501 |
| 50/50 LightGBM31 + XGBoost6 | 0,64814 | 0,65747 |

Увеличение глубины XGBoost не помогло на обоих разбиениях. Более крупный LightGBM
не победил на обоих. Сохранены разные семейства и проверяемый выбор кандидата,
а не фиксированный победитель для любого набора данных. Sqrt-веса помогли
на обоих разбиениях. Настройка class-bias на внутреннем holdout не улучшала
взвешенные модели устойчиво, поэтому автоматическая калибровка не добавлена.
Первоначальные CatBoost-контроли с неполным refit не получили оценку; таблица
использует только завершённые повторные контрольные запуски.

Исходные отчёты: `.test-temp/night-classification-summary.json`,
`.test-temp/night-classification-extra-report.json`. Внешних API-вызовов нет.

## Повторная проверка дополнительных улучшений

Две стратегии новых признаков проверены по прежнему вложенному групповому
протоколу: список/статистика выбираются только на внутреннем train, затем
фиксируются для внешнего refit. Внешние ответы не используются для обучения.
В таблице приведены Macro F1 на основном и подтверждающем разбиениях.

| Изменение | Модель | Основной: было → стало | Подтверждающий: было → стало |
|---|---|---:|---:|
| Частоты категорий | LightGBM63 | 0,64148 → 0,64835 | 0,66294 → 0,66026 |
| Частоты категорий | XGBoost6 | 0,65191 → 0,64001 | 0,64997 → 0,64652 |
| Целочисленные признаки с 2–16 значениями как категории | LightGBM63 | 0,64148 → 0,63730 | 0,66294 → 0,65331 |
| То же | XGBoost6 | 0,65191 → 0,64441 | 0,64997 → 0,65169 |

Устойчивого выигрыша нет, обе автоматические стратегии отклонены. Для опыта с
ролями исправлены экспериментальные вызовы LightGBM: предварительные прогоны,
где новая роль не доходила до fit, исключены; таблица содержит только корректные
повторные опыты. Промежуточное улучшение одного разбиения не стало основанием
для изменения дефолтов.

Сравнение вычислительного бюджета выполнено при одинаковых четырёх потоках.
Warmup 300/600 секунд дал один F1 0,655436; фактическое время выросло с 172,9
до 244,2 секунды. Регрессия с увеличенным бюджетом осталась на RMSE 43,272422.
XGBoost patience 180 также сохранил 300 выбранных деревьев и F1 0,644415.
Дефолтные warmup и patience сохранены.

Дополнительно те же выбранные параметры и числа деревьев без нового early stopping
проверены на grouped17: ансамбль обоих расписаний дал F1 0,651824. Разбиения
пересекаются по исходным данным; это проверка чувствительности CV, не внешний тест.

В код вошли два исправления: отдельная предобработка каждой модели внутри ансамбля
и выделение бюджета refit только компонентам, которые ещё не обучены на полном train.
Оба подтверждены тестами с настоящими моделями и сохранёнными артефактами.

Отчёты: `.test-temp/feature-frequency-report.json`,
`.test-temp/feature-role-report.json`, `.test-temp/schedule-summary.json`.
Новых платных API-вызовов нет.

## Дробная степень весов классов

Проверены степени 0,25 и 0,75 вместо текущего SqrtBalanced (0,5) для LightGBM63
и XGBoost6: восемь заранее заданных опытов на прежних двух внешних групповых
разбиениях. Веса считались на соответствующем train-fold и нормировались до
среднего 1; число деревьев выбиралось на внутреннем holdout. Вызовы fit проверяли,
что использована нужная степень, а внешние ответы не участвуют в вычислении весов.
