# Дополнительное исследование: редкие классы и современные методы

26 октября 2026. Runtime не изменён. Все эксперименты локальные, внешних API нет.

## Дисбаланс классов

В готовом конвейере уже используется SqrtBalanced. Две группы независимых
экспериментов проверены на фиксированных внешних групповых разбиениях; число
деревьев выбиралось внутри train. Контроли заново обучены тем же native-кодом,
поэтому они не смешиваются со старыми sklearn-контролями или runtime-score.

Oversampling: число строк класса доводилось до ceil(sqrt(n_max*n_class)),
повторялись только реальные строки обучающей части после разделения групп.
Дополнительные class weights отключены. Валидация не размножалась.

| Модель | Основной: контроль → oversampling | Подтверждающий |
|---|---:|---:|
| LightGBM | 0,649607 → 0,645360 | 0,643278 → 0,652156 |
| XGBoost | 0,642598 → 0,636842 | 0,639676 → 0,641974 |

Результаты смешанные. Замена LightGBM в текущем ансамбле дала 0,656161 против
0,656210: подтверждённого улучшения готового решения нет. Повторение строк
увеличило общую массу loss примерно в1,48 раза и изменило относительную
регуляризацию. Отдельный mass-normalized контроль не выполнялся; эффект
нельзя приписывать исключительно балансировке. Oversampling не включён.

Focal loss: мультиклассовая softmax-версия с gamma2 и SqrtBalanced alpha.
Градиент и полный Hessian независимо проверены finite differences. Для
XGBoost использована положительная диагональная оценка кривизны: это не точный
Hessian и не гарантия глобальной сходимости. При gamma0 tiny-контроль совпадает
с native weighted softmax с разницей вероятностей до1,81e-8.

| XGBoost | Weighted CE | Focal gamma2 |
|---|---:|---:|
| Основной holdout | 0,642598 | 0,632865 |
| Подтверждающий | 0,639676 | 0,623181 |

Оба внутренних focal-прогона ограничены временем; выбраны783/67 законченных
раундов. Внешние модели точно дообучены на это число раундов без внешнего early
stopping. Неполные внешние модели не оценивались. Проверенный бюджетный вариант
хуже на обоих разбиениях; это не доказательство бесполезности любой focal loss.

[Оригинальная статья focal loss](https://arxiv.org/abs/1708.02002) описывает
понижение вклада простых примеров. Мультиклассовые производные выведены отдельно.
[Документация XGBoost](https://xgboost.readthedocs.io/en/release_3.0.0/tutorials/advanced_custom_obj.html)
объясняет ограничения custom objectives и диагональные приближения кривизны.

## Неоднозначность признаков

Среди всех известных train-строк у70,9% Analysis и72,6% Backdoor имеются строки
с точно такими же исходными признаками и другой меткой. ID исключён из признаков.
Это описательная статистика, не оценка качества и не верхняя граница Macro F1.
Она не использовалась для выбора весов или обучения. Различающего контекста
может не хватать; размножение таких строк само по себе не создаёт информацию.

Отчёты и код: .test-temp/rare-oversampling-report.json,
rare-focal-report.json, rare-label-ambiguity.json, focal-math-proof.json,
focal-runner-audit.json. Данные и обученные модели не публикуются.

## Проверка свежих подходов

Проверены официальные источники актуальных TabICLv2, TabPFN-3 и TabM:

- [TabICLv2, ICML2026](https://github.com/soda-inria/tabicl): требует пакет и pretrained checkpoint.
- [TabPFN-3](https://github.com/PriorLabs/TabPFN): требует пакет, веса и принятие лицензии; для крупных таблиц рекомендован GPU.
- [TabM, ICLR2025](https://github.com/yandex-research/tabm): эффективный ансамбль MLP на PyTorch, без обязательного pretraining.

Эти пакеты отсутствуют в предоставленном списке зависимостей; pretrained-веса
не переносятся платформой из ZIP. Локальный venv также не содержит PyTorch.
Для TabM возможна собственная реализация на разрешённом PyTorch, но её нужно
обучить, сравнить и проверить отдельно. Непроверенная архитектура не добавлена.

[TabArena, NeurIPS2025](https://proceedings.neurips.cc/paper_files/paper/2025/hash/1697e3fb412da11dc9488249f9e7bbc9-Abstract-Datasets_and_Benchmarks_Track.html)
подчёркивает пользу ансамблей разных конфигураций. По этой идее выполнен один
заранее заданный дешёвый тест: равная смесь LightGBM31, LightGBM63 и XGBoost6
по сохранённым nested-предсказаниям с проверкой одинакового порядка строк.

| Разбиение | Новый ансамбль | Текущий nested-тройной |
|---|---:|---:|
| Основное | 0,645941 | 0,654603 |
| Подтверждающее | 0,660221 | 0,657263 |

Улучшение не подтверждено на обоих разбиениях; вариант отклонён. Это один
ограниченный тест, а не исчерпывающий поиск всех архитектур или конфигураций.
Report: .test-temp/latest-config-ensemble-report.json. Проверенный ZIP сохранён.
