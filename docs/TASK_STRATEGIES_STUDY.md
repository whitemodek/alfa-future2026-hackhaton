# Специализированные стратегии для двух задач

26 октября 2026. Проверены две предметные архитектуры. Рабочее решение уже
обучает отдельные модели на каждой задаче; универсальной остаётся организация
валидации, поиска и публикации. Объектно-ориентированная структура сама по себе
не меняет ML-качество. Здесь проверялось именно изменение схемы обучения.

## Сетевые атаки: иерархия

Прототип `HierarchicalAttackStrategy` объединяет два независимых адаптера:

1. Невзвешенная бинарная LightGBM оценивает вероятность атаки, выбирая число
   деревьев по внутреннему log loss.
2. LightGBM с SqrtBalanced различает девять типов только среди атак.

Совместные вероятности: P(Normal)=1−P(attack),
P(type)=P(attack)×P(type|attack). Класс Normal сохраняет исходный индекс.
Класс стратегии инкапсулирует fit/refit/predict_proba; refit не принимает
валидационные ответы и возвращает отдельную модель.

На внутреннем разбиении выбирается сила смеси с историческим ансамблем
из 0/0,25/0,5/1. Все внешние модели обучаются на точно выбранное внутреннее
число деревьев. Внешние ответы не участвуют в fit, early stopping и выборе веса.

| Разбиение | Исторический контроль Macro F1 | Выбранная смесь | Разница |
|---|---:|---:|---:|
| Основное | 0,654210 | 0,650814 | −0,003396 |
| Подтверждающее seed17 | 0,660766 | 0,641924 | −0,018843 |

На внутренних разбиениях качество улучшалось, на внешних — ухудшилось.
Это важный отрицательный результат переноса, а не основание отбирать
конфигурацию по более красивой внутренней оценке. Контроль — исторический
ансамбль из согласованных кэшей, а не точный рабочий релиз с F1=0,656210.

Заранее требовался прирост не менее0,002 на обоих внешних разбиениях.
Условие не выполнено, вариант не включён в runtime.

## Здания: прогноз изменения относительно прошлого

Модель учит остаток y−last_past_y только на строках, у которых есть
однозначное строго прошлое наблюдение. Прогноз восстанавливается как
last_past_y+predicted_delta. Затем применяется заранее заданная смесь50/50
с сохранённым историческим конвейером. Строки без истории сохраняют
исходный рабочий прогноз без изменений.

Временные границы, внутренний early stopping и точный внешний refit
аналогичны исследованию причинной статистики. Число выбранных деревьев
составило111 для периода5 и1 для периода4; менять его по внешним оценкам нельзя.

| Внешний период | Сохранённый рабочий RMSE | Прогноз изменения | Разница |
|---|---:|---:|---:|
| 5 | 37,165878 | 37,299053 | +0,133175 |
| 4 | 32,643254 | 31,042355 | −1,600899 |

Рабочий контроль ранее использовал внешний early stopping, новая модель —
внутренний. Это сравнение с сохранённым результатом, а не парная оценка
исключительно влияния остаточной цели. Второй контроль является историческим.
Заранее требовалось уменьшение RMSE минимум на0,1 на каждом периоде.
Условие не выполнено; вариант не включён в runtime.
