# Проверка специалиста по атакам и причинной статистики

26 октября 2026. Два заранее ограниченных исследования без внешнего API.
Параметры, разбиения и условия продолжения записаны до оценки внешних результатов.
Использованные holdout уже встречались при разработке: это исследование,
а не новый слепой тест или оценка скрытого балла платформы.

## Специалист по атакам

Заранее выбраны Analysis, Backdoor, DoS, Exploits. LightGBM обучается только
на этих классах из обучающей части. Его условные вероятности перераспределяют
суммарную вероятность этой группы; остальные классы и общая масса сохраняются.
Сила вмешательства выбирается из 0/0,25/0,5 только на внутренней валидации
по Macro F1 всех десяти классов. Число деревьев также выбирается внутри train.
Внешняя модель дообучается на выбранное число итераций без внешнего early stopping.

| Групповое разбиение | Исследовательский контроль | Специалист | Разница |
|---|---:|---:|---:|
| Основное | 0,654210 | 0,658807 | +0,004597 |
| Подтверждающее seed17 | 0,660766 | 0,661487 | +0,000721 |

Контроль — исторический согласованный ансамбль с кэшированными внутренними
и внешними предсказаниями. Это не точная конфигурация рабочего релиза
с Macro F1=0,656210. Нельзя приписывать рабочему решению разницу из таблицы.

Предзаданное условие продолжения: не менее +0,002 на каждом разбиении
при ненулевом выбранном весе. Это инженерный порог, не тест значимости.
Условие не выполнено. В рабочий конвейер специалист не включён,
новые группы и веса по внешним результатам не подбирались.

## Причинная статистика истории

Сравниваются текущие два признака — последний прошлый таргет и доступность —
с шестью: дополнительно среднее двух последних наблюдений, тренд на единицу
периода, время с последнего наблюдения и число известных прошлых наблюдений.

Каждая обучающая строка получает только строго предшествующие значения.
Собственные и будущие таргеты не используются. Запрос не принимает целевой
столбец прогнозируемых строк. Неоднозначные и неполные ключи не получают
историю; коллизия отключает ключ только после появления соответствующего периода.

Для внешнего периода5 обучение использует периоды1–4, внутренняя проверка —4.
Для внешнего периода4 обучение использует1–3, внутренняя проверка —3.
Конфигурация XGBoost фиксирована. Число деревьев выбирается только внутри;
внешний refit повторяет его точно, без внешнего early stopping.

| Внешний период | Два признака: RMSE | Шесть: RMSE | Разница |
|---|---:|---:|---:|
| 5 | 38,482527 | 37,869454 | −0,613073 |
| 4 | 35,857170 | 35,756099 | −0,101071 |

Предзаданный порог улучшения0,1 RMSE на каждом периоде пройден.
Таблица относится только к отдельной модели, а не к готовому ансамблю.
Для решения об интеграции требуется отдельное сравнение полной смеси
с сохранённой исторической моделью.

Дополнительная проверка выполнена с фиксированной смесью 50/50:

| Период | Парная смесь с двумя признаками | Смесь с шестью | Сохранённый рабочий результат |
|---|---:|---:|---:|
| 5 | 37,346461 | 37,044449 | 37,165878 |
| 4 | 33,317922 | 33,277510 | 32,643254 |

Историческая часть смеси одинакова внутри каждой пары. На периоде5
она восстановлена из исходных holdout-моделей последнего релиза с проверкой
исходной оценки. На периоде4 используется ранее сохранённый контроль.
Рабочие результаты в последнем столбце выбирали число деревьев по внешнему
holdout; новые модели — по внутреннему. Это разные протоколы, а не
прямой парный эксперимент между первым и последним столбцами.

Кандидат лучше рабочего результата на периоде5, но хуже на периоде4.
Условие улучшения обоих сохранённых результатов не выполнено.
Повторный прогон с сохранением моделей, индексов и прогнозов воспроизвёл
первоначальные результаты. В рабочий архив статистика не включена.

## Проверки изоляции

- Пересечения строк и групп между train/validation отклоняются до fit.
- Внутренние разбиения полностью лежат внутри внешнего train.
- Изменение собственного или будущего таргета не меняет более ранние признаки.
- Таргеты query не читаются; пересечение его периодов с обучением отклоняется.
- Проверены пропуски, бесконечности, неравномерные интервалы и одинаковые
  строки с коллизией ключа в одном периоде.
- Для первых двух признаков проверено совпадение с рабочим causal_lags.
- Исходные данные неизменны. Сохраняются хеши протокола, индексов и прогнозов;
  для повторного прогона статистики — также модели и их хеши.
